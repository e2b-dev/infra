# Typed public IDs

This package converts resource UUIDs to and from human-readable public IDs:

```text
prj_7mfb0gpp6c8dsaasre0asc7n3s
wrk_2n1t201rmv87aae5j4csam8000
sec_01kyjhkfvse96rg4d2qzd9enft
```

Every public ID has a stable resource prefix, an underscore, and a
26-character UUID suffix. E2B's public representation is always lowercase.

## UUID ownership

Resource owners remain responsible for generating and storing UUIDs. UUIDs
may, for example, be generated by application code or a database. This package
does not use `typeid.New` or `typeid.MustNew`.

[`github.com/sumup/typeid`](https://github.com/sumup/typeid) is used only to
convert an existing UUID to its prefixed public representation and parse that
representation back into the UUID-backed resource type. PostgreSQL and other
persistence layers continue to store the underlying UUID, not the prefixed
string.

```go
projectUUID := uuid.New()
projectID := id.ProjectID(projectUUID)

publicID := projectID.String()
parsedID, err := id.ParseProjectID(publicID)
if err != nil {
	return err
}

projectUUID = uuid.UUID(parsedID)
```

Project and workspace UUIDs are normally UUIDv4 and use `typeid.Random`.
Secret UUIDs are UUIDv7 and use `typeid.Sortable`. SumUp renders Random IDs in
uppercase, so the E2B wrapper normalizes them to the lowercase public contract.

## Adding a resource ID

To add another public resource ID:

1. Choose a short, stable, lowercase prefix that keeps the full public ID at
   the expected fixed width.
2. Add a private prefix type implementing `Prefix()`.
3. Select `typeid.Random` for a UUIDv4 resource or `typeid.Sortable` for a
   UUIDv7 resource.
4. Add a distinct UUID-backed public Go type with `String` and parse methods.
5. Keep UUID generation in the resource-owning application or database.
6. Test the exact prefix, lowercase output, fixed length, invalid-prefix
   rejection, and UUID round trip.

Do not add JSON, text, SQL, or UUID-generation behavior implicitly. Those
interfaces should be introduced only when a concrete caller needs them.
